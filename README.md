# ZRYSPOTY

Polski odtwarzacz muzyczny z lokalną biblioteką i importem własnych plików audio.

## Linki Spotify

Otwórz **Linki Spotify**, wklej adres skopiowany przez **Udostępnij → Kopiuj link** i wybierz **Dodaj do biblioteki**. Zakładka przyjmuje też linki do albumów i playlist oraz kilka adresów naraz. W wersji przeglądarkowej dostępny jest osadzony odtwarzacz Spotify, a na Androidzie i we Flatpaku link otwiera się w Spotify lub przeglądarce.

## Pobierz

- [Linux DEB](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.2/ZRYSPOTY-Linux.deb) — Debian, Ubuntu i pochodne. Zainstaluj przez `sudo apt install ./ZRYSPOTY-Linux.deb`.
- [Linux Flatpak](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.2/ZRYSPOTY-Linux.flatpak) — zainstaluj przez `flatpak install ./ZRYSPOTY-Linux.flatpak`. Pakiet korzysta ze środowiska GNOME 50 z Flathub.
- [Windows EXE 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.2/ZRYSPOTY-Windows-x64.exe) — uruchom pobrany plik.
- [Linux AppImage 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.2/ZRYSPOTY-Linux-x86_64.AppImage) — nadaj uprawnienie do wykonania i uruchom plik.
- [Android APK](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.2/ZRYSPOTY-Android.apk) — pakiet podpisany kluczem testowym.

Wersje DEB, AppImage i EXE uruchamiają odtwarzacz w domyślnej przeglądarce. Przycisk **Wyszukaj w Spotify** otwiera wyniki w Spotify.
