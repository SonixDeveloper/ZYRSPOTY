# ZRYSPOTY

Polski odtwarzacz muzyczny z lokalną biblioteką i importem własnych plików audio.

## Pobierz

- [Linux DEB](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Linux.deb) — Debian, Ubuntu i pochodne. Zainstaluj przez `sudo apt install ./ZRYSPOTY-Linux.deb`.
- [Linux Flatpak](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Linux.flatpak) — zainstaluj przez `flatpak install ./ZRYSPOTY-Linux.flatpak`. Pakiet korzysta ze środowiska GNOME 50 z Flathub.
- [Windows EXE 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Windows-x64.exe) — uruchom pobrany plik.
- Linux AppImage i Android APK — znajdziesz w [wydaniu 1.0.1](https://github.com/SonixDeveloper/ZYRSPOTY/releases/tag/v1.0.1) po ukończeniu [budowy](https://github.com/SonixDeveloper/ZYRSPOTY/actions/workflows/release.yml).

Wersje DEB, AppImage i EXE uruchamiają odtwarzacz w domyślnej przeglądarce. Przycisk **Wyszukaj w Spotify** otwiera wyniki w Spotify.
