# ZRYSPOTY

Polski odtwarzacz muzyczny z lokalną biblioteką i importem własnych plików audio.

## Pobierz

- [Linux DEB](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.1/ZRYSPOTY-Linux.deb) — Debian, Ubuntu i pochodne. Zainstaluj przez `sudo apt install ./ZRYSPOTY-Linux.deb`.
- [Linux Flatpak](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.1/ZRYSPOTY-Linux.flatpak) — zainstaluj przez `flatpak install ./ZRYSPOTY-Linux.flatpak`. Pakiet korzysta ze środowiska GNOME 50 z Flathub.
- [Windows EXE 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.1/ZRYSPOTY-Windows-x64.exe) — uruchom pobrany plik.
- [Linux AppImage 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.1/ZRYSPOTY-Linux-x86_64.AppImage) — nadaj uprawnienie do wykonania i uruchom plik.
- [Android APK](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.1/ZRYSPOTY-Android.apk) — pakiet podpisany kluczem testowym.

Wersje DEB, AppImage i EXE uruchamiają odtwarzacz w domyślnej przeglądarce. Przycisk **Wyszukaj w Spotify** otwiera wyniki w Spotify.
