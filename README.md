# ZRYSPOTY

Polski odtwarzacz muzyczny z lokalną biblioteką i importem własnych plików audio.

## Profile bez hasła i e-maila

Kliknij ikonę profilu przy wyszukiwarce, wpisz nazwę i wybierz **Utwórz profil**. Później możesz wrócić do profilu, wybierając go z listy. Pierwszy profil zachowuje dotychczasową bibliotekę.

Profile i ich biblioteki są zapisane lokalnie na urządzeniu. Przełączenie profilu nie wymaga weryfikacji tożsamości.

## Linki muzyczne

Otwórz **Linki muzyczne**, wklej adres utworu lub playlisty ze Spotify, YouTube albo YouTube Music i wybierz **Dodaj do biblioteki**. Możesz wkleić kilka adresów naraz, po jednym na wiersz.

Użyj **Odtwórz tutaj**, gdy osadzony odtwarzacz jest dostępny. YouTube można odtwarzać w APK na Androida lub w wersji internetowej na HTTPS, jeśli dany materiał pozwala na osadzanie. Link do otwarcia w serwisie jest dostępny przy każdym wpisie.

## Pobierz

- [Linux DEB](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.5/ZRYSPOTY-Linux.deb) — Debian, Ubuntu i pochodne. Zainstaluj przez `sudo apt install ./ZRYSPOTY-Linux.deb`.
- [Linux Flatpak](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.5/ZRYSPOTY-Linux.flatpak) — zainstaluj przez `flatpak install ./ZRYSPOTY-Linux.flatpak`. Pakiet korzysta ze środowiska GNOME 50 z Flathub.
- [Windows EXE 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.5/ZRYSPOTY-Windows-x64.exe) — uruchom pobrany plik.
- [Linux AppImage 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.5/ZRYSPOTY-Linux-x86_64.AppImage) — nadaj uprawnienie do wykonania i uruchom plik.
- [Android APK](https://github.com/SonixDeveloper/ZYRSPOTY/releases/download/v1.0.5/ZRYSPOTY-Android.apk) — pakiet podpisany kluczem testowym.

Wersje DEB, AppImage i EXE uruchamiają odtwarzacz w domyślnej przeglądarce. Przycisk **Wyszukaj w Spotify** otwiera wyniki w Spotify.
