# ZYRSPOTY

ZRYSPOTY to polski odtwarzacz muzyczny z lokalną biblioteką i importem własnych plików audio.

## Pobierz

- [Linux](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Linux.tar.gz) — rozpakuj pakiet i uruchom `./Zainstaluj.sh`, aby dodać ZRYSPOTY do menu aplikacji.
- [Windows 64-bit](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Windows-x64.zip) — rozpakuj cały ZIP i uruchom `ZRYSPOTY.exe`.
- [Android (projekt do Android Studio)](https://github.com/SonixDeveloper/ZYRSPOTY/raw/refs/heads/main/downloads/ZRYSPOTY-Android-projekt.zip) — archiwum zawiera projekt do budowania APK.

Wersje dla Linuksa i Windowsa otwierają odtwarzacz w domyślnej przeglądarce. Przycisk **Wyszukaj w Spotify** otwiera wyniki w Spotify.
